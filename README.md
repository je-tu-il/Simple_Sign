# Simple Sign ✍️

Application web légère, autonome et prête à l'emploi pour créer des signatures manuscrites au trackpad, doigt ou souris.

## Fonctionnalités

- **Tracé fluide & naturel** : Utilise l'API `PointerEvents` avec lissage via courbes de Bézier pour un rendu fluide au glissement de doigt sur le trackpad.
- **Édition & contrôle** :
  - Choix de couleur d'encre.
  - Réglage de l'épaisseur du trait (1px à 15px).
  - Boutons **Annuler** (`Undo`) et **Rétablir** (`Redo`).
  - Effacer tout en un clic.
- **Export & partage** :
  - **PNG** haute définition.
  - **SVG** vectoriel (infiniment redimensionnable sans perte).
  - **Copier** directement dans le presse-papier pour coller sur un document.
  - Option **Fond transparent** ou blanc.
  - Option **Rognage automatique** (découpe les marges blanches pour ne garder que la signature).
